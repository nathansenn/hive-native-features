# 05 – Continuous Integration

**Task-ID:** swarm / CI  
**Status:** implemented  
**Last Updated:** 2026-07-25  

---

## 1. Purpose

Automate configure → build → test → microbenchmark on every push and pull request so broken tests never land unnoticed, and so accidental private-key material is rejected before merge.

CMake is **not** modified by this work; workflows call the existing `CMakeLists.txt` targets only.

## 3. Workflow: `ci.yml`

**Triggers:** `push`, `pull_request`  
**Runner:** `ubuntu-latest`

| Step | Action |
|------|--------|
| Install | `cmake`, `g++`, `make` via `apt-get` |
| Configure | `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release` |
| Build | `cmake --build build --parallel` |
| Test | `ctest --test-dir build --output-on-failure` — **job fails if any test fails** |
| Bench | Runs `./build/hive_native_bench` (built when `HIVE_NATIVE_BUILD_BENCH` is ON, the CMake default) |

### Targets exercised (from existing CMake)

- Library: `hive_native`
- Test executable / CTest name: `hive_native_tests`
- Benchmark executable: `hive_native_bench`

No optional Wasmtime linkage (`HIVE_NATIVE_WITH_WASMTIME` stays off in CI).

---

## 4. Workflow: `secret-scan.yml`

**Triggers:** `push`, `pull_request`  
**Runner:** `ubuntu-latest`

Scans **tracked** files with `git grep` for PEM private-key headers, including:

- `BEGIN PRIVATE KEY`
- `BEGIN RSA PRIVATE KEY`
- `BEGIN OPENSSH PRIVATE KEY`
- `BEGIN EC PRIVATE KEY`
- `BEGIN DSA PRIVATE KEY`

If any match is found (outside the workflow file’s own pattern string exclusion), the job exits non-zero.

This is a simple guard aligned with README constraint **“No secrets in git history”**. It is not a full secret-scanning product (no entropy analysis, no cloud scanner).

---

## 5. Failure policy

| Condition | Result |
|-----------|--------|
| Configure or compile error | CI job fails |
| Any CTest failure | CI job fails (`ctest` non-zero) |
| Bench binary crash / non-zero exit | CI job fails |
| Private-key marker in tracked files | Secret-scan job fails |

Either workflow failing should block merge once branch protection is enabled on the default branch.

---

## 6. Local parity

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/hive_native_bench
git grep -nE 'BEGIN (RSA |OPENSSH |EC |DSA )?PRIVATE KEY|BEGIN RSA PRIVATE KEY' -- . || true
```

---

## 7. Out of scope (this addition)

- Changing `CMakeLists.txt` or test/bench sources
- Installing Wasmtime or enabling `HIVE_NATIVE_WITH_WASMTIME`
- Coverage, sanitizers, matrix of compilers
- Third-party secret scanners (e.g. gitleaks, trufflehog)

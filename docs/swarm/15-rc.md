# Swarm Brief 15 – Resource Credits (RC)

**Audience:** Evaluator / Apply Coder, Performance Benchmarker, Reviewer, Test agent  
**Canonical model:** [`docs/08-rc-cost-model.md`](../08-rc-cost-model.md)  
**Code:** `include/hive_native/rc/costs.hpp`, `src/rc/costs.cpp`  
**Task-IDs:** phase-1 / 1.4 · phase-2 RC · phase-3d fuel→RC  

---

## 1. Mission

Every new operation **must** charge RC. Placeholders are OK only with an explicit **`TODO – measure`** and TASK-ID. Absolute Hive RC units are *not* claimed here — we use relative micro-units (`TRANSFER_BASE = 1000`).

---

## 2. Constants (memorize)

| Name | Value | Rule of thumb |
|------|------:|---------------|
| `TRANSFER_BASE` | 1000 | 1× transfer-class op |
| `bytes_cost(n)` | `n × 2` | Linear size tax |
| `FUEL_TO_RC_NUM` / `DEN` | 1 / 10 | **10 fuel → 1 RC micro** |

---

## 3. Formula cheat sheet

```text
bytes_cost(n) = 2·n

NFT
  create_collection = 3·B + bytes(symbol+name) + 500
  mint              = 2·B + bytes(uri) + 800
  transfer          = B + bytes(memo)
  approve           = B/2
  set_approval_all  = B/2 + 100
  burn              = B

HTLC
  create = 2·B + bytes(memo) + 600
  redeem = B + bytes(preimage) + 200
  refund = B

Contracts
  deploy = 10·B + bytes(code) + (fuel_limit · NUM)/DEN
  call   =  2·B + bytes(args) + (fuel · NUM)/DEN
           fuel = fuel_used if ≠ 0 else fuel_limit

B = TRANSFER_BASE
```

Wire-up: evaluators set `db.last_rc_charged = rc::cost_*(...)`.

---

## 4. Agent duties

| Role | Must do |
|------|---------|
| **Evaluator Coder** | Call the matching `cost_*` on every apply path; no free ops |
| **Protocol Coder** | Cap field sizes so `bytes_cost` stays bounded |
| **Test agent** | Smoke: transfer ≥ B; mint > transfer; fuel branch for calls |
| **Performance Benchmarker** | Replace placeholders via measure; never lower cost without human review |
| **Reviewer** | Reject free DoS surfaces; check state-create ops stay expensive |
| **GitOps** | Universal checklist: “RC defined or TODO – measure” |

---

## 5. TODO – measure (do not “fix” by inventing numbers)

Upstream / later-phase calibration targets:

1. Map micro-units → real Hive RC resource-user map  
2. NFT state flats (+500 / +800) vs object byte weights  
3. HTLC create deterrence (+600) and redeem hash (+200)  
4. Contract deploy base (×10) and `FUEL_TO_RC_*` slope (Phase 3d)  
5. Host storage-write RC beyond op-field `bytes_cost`  
6. Block fuel caps (`04-performance-budgets.md` §7)

Full table: **`docs/08-rc-cost-model.md` §9**.

---

## 6. Fail closed

- New op without `cost_*` or without `TODO – measure` + TASK-ID → **block commit**  
- RC decrease that enables spam → **human review**  
- Contract execution over `fuel_limit` → **must be impossible**  
- Consensus activation of uncalibrated costs → **human HF gate**
